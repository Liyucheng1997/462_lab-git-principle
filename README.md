# Git 原理 · 三维交互图解

用 Three.js 把 Git 的内部原理和日常用法画成可以动手操作的三维场景。

## 运行

页面使用 ES 模块，需要通过本地服务器打开（不能直接双击 `index.html`）：

```
python -m http.server 4620
```

然后访问 <http://localhost:4620>。Windows 下也可以直接双击 `启动.bat`。

没有构建步骤，也不依赖网络：Three.js 已放在 `vendor/` 里。

## 内容

十个章节，每章左边是讲解，右边是三维场景，下面是可以自己敲命令的终端：

1. Git 是什么　2. 三个区域　3. 对象模型　4. 分支与 HEAD　5. 合并
6. 变基与拣选　7. 撤销与找回　8. 远程协作　9. .git 内部　10. 命令速查

场景里能看到：工作区 / 暂存区 / 版本库三块平台上的文件卡片、提交图、分支与 HEAD 标签、
tree 和 blob 对象层、远程仓库，以及变基或重置后留下的不可达提交。

## 结构

| 文件 | 作用 |
| --- | --- |
| `js/git.js` | 迷你 Git 引擎。对象格式和 SHA-1 与真实 Git 一致，所以哈希也一致 |
| `js/scene.js` | Three.js 场景：按仓库状态增删节点并做补间动画 |
| `js/chapters.js` | 各章的讲解文字、预置仓库和演示步骤 |
| `js/main.js` | 教程面板、终端、对象 / .git 面板 |
| `css/tokens.css` | 设计变量（颜色、圆角、阴影） |

## 与真实 Git 的差别

- 合并只比较到整个文件：两边改了同一个文件的不同行，真实 Git 能自动合并，这里会报冲突。
- 变基、拣选遇到冲突会直接中止，不支持 `--continue`。
- `stash` 没有像真实 Git 那样存成提交对象。
- 没有 packfile，`git gc` 只做不可达对象的回收。
